## What changed

- `GET /api/autopilot/signals` returns a `SignalsBundle`: `generated_at`, `signals[]`, and `errors[]`. Each signal carries `source`, `url`, `title`, `text`, `posted_at`, and optional `handle` and `score_hint`. `source` is one of `x_search`, `hn`, `hf_papers`, `rss`, `bluesky`, `github`.
- `SignalsService` runs the six collectors concurrently. Each collector has a 20s timeout. A timeout or exception becomes an `errors[]` entry and the other signals are still returned. Logs record the source and the exception type.
- URLs are deduped by canonical form (lower scheme and host, fragment and trailing slash removed, query kept). The first occurrence wins. The bundle is capped at 200 signals.
- A process-wide cache holds the bundle, including any errors, for 30 minutes. Concurrent callers share one collection.
- The X collector searches via `ddgs` (`timelimit=d`, `max_results=10`) with the three architecture queries, spaced 2-5 seconds, capped at six queries. Only `https://(x|twitter).com/<handle>/status/<id>` is kept, rewritten to `https://x.com`. Post time comes from the snowflake id. Posts older than 48 hours are dropped. The backend does not request x.com. `score_hint` is how many distinct queries returned that status.
- `AUTOPILOT_X_RESOLVER` defaults to `none` (`NoneResolver`, no I/O). `mirror` GETs `https://{AUTOPILOT_X_MIRROR_HOST}/{handle}/status/{id}` with redirects disabled. HTTP 451, other non-2xx responses, and block pages leave the snippet in place. A resolve is capped at 3 seconds.
- Hacker News uses the Algolia search API (`tags=story`, `points>100`, created within 48 hours) for AI, LLM, Claude, GPT, Gemini, and Grok. Hugging Face reads `/api/daily_papers`. Bluesky reads the public `getTrends` AppView and prefixes relative links with `https://bsky.app`. GitHub searches `topic:llm` created in the last 7 days, sorted by stars. `GITHUB_TOKEN` is sent only when it is non-blank.
- RSS uses `defusedxml` (direct runtime dependency). One bad feed is skipped. Every feed failing is a collector error.

## Deviations

- Anthropic publishes no RSS. `https://www.anthropic.com/sitemap.xml` is the substitute, limited to paths containing `/news/`, with a 14-day max age so the sitemap does not fill the 200-signal cap.
- The Meta AI blog RSS returned 404. The collector uses `https://engineering.fb.com/category/ml-applications/feed/`.
- Google AI uses the canonical feed `https://blog.google/innovation-and-ai/technology/ai/rss/`.
- GitHub's date window was unspecified. `GITHUB_LOOKBACK_DAYS` is 7. Hacker News queries are the model names used in the X query, plus `AI`.
- The mirror resolver returns visible text. Like and repost counts are not parsed. The default stays `none`.
- The import-linter contracts for this module already exist from AE-0350. This ticket does not add another.
- Signal, collector error, and bundle types are frozen dataclasses. A Pydantic model in this module trips mypy `explicit-any`. FastAPI serializes the dataclass response.

## Known risks

- The 30-minute cache stores a bundle that includes collector errors, so a transient failure is served until the TTL expires.
- The shipped X query list is the three architecture examples. Six queries at the 5 second spacing ceiling can exceed the 20 second collector timeout.
- `AUTOPILOT_X_RESOLVER=none` and an empty `GITHUB_TOKEN` are valid. Production does not need either secret for this ticket. AE-0359 owns deploy wiring. The mirror host is unused while the resolver is `none`.
