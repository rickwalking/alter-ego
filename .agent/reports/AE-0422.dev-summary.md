## What changed

Wave A of ADR-0025: the public blog body renders text only, and the carousel write path no
longer creates/overwrites/publishes blog rows. Per acceptance criterion:

- **AC1** `blog-post-content.tsx` renders `ReactMarkdown` per section and reads no carousel
  design image; `themeOnlyDesign()` (`src/lib/public-blog.ts`) keeps the design colors/typography
  and strips `images` (`hero`/`slides`/`rendered_slides_pt`/`rendered_slides_en`/`blog_image_map`).
  `images.hero` is itself a `/slide-images/` URL (`design_token_utils.py`), so the whole design
  image payload is dropped for carousel posts; a standalone post keeps its own `featured_image_url`.
- **AC2** removed `resolveSlideImage`, `ResolveSlideImageOptions`, the positional `slideImage`
  fallback, `slideImages`, the `blog_image_map` read, `extractH2Heading`, and the unused
  `CAROUSEL_SLIDE_WIDTH/HEIGHT`; dropped the removed symbols from the publishing barrel.
- **AC3** the design fetch is theme-only; a standalone post with no tokens uses the default theme.
- **AC4** the title still renders exactly once.
- **AC5** `blog_clean_slides.feature` marked SUPERSEDED by ADR-0025; the positional mapping
  scenarios in `blog_content_cleanup.feature` marked superseded; the preview-hero scenario in
  `public-blog-polish-ae0412.feature` replaced by "Post page surfaces no carousel design image".
- **AC6** new `infrastructure/database/blog_post_hide.py`: `is_hide_target` selects every published
  carousel-origin row (no body-length/H1 filter); `BlogPostHideService.hide` runs the unpublish
  transition (status → draft, clear stamps, bump `lock_version`), writes
  `ai_generation_metadata.hidden_bad_post = {at, reason}`, and emits the status event via the
  outbox; idempotent, never deletes. Operator CLI `scripts/hide_bad_carousel_posts.py` (dry-run
  default). Prod run stays the orchestrator's action.
- **AC7** removed `sync_carousel_blog_post` + its `create_project`/`update_project` calls; deleted
  `carousel_blog_dual_write.py` and folded `_detach_carousel_blog_posts` into
  `carousel_repository.py` (delete still drafts a published carousel blog row). Distribution mirror
  preserved via `write_distribution`.

## Decisions

- Drop the whole carousel design image, including `hero` (AC1 forbids any `/slide-images/` src and
  the hero is one).
- Repoint the ADR-0011 distribution write to `write_distribution` (no-op without a row; never
  touches `content`/`status`).
- AC6 service lives in `infrastructure/database` (next to `workflow_timeout_repository`) to avoid a
  new `application -> infrastructure` edge in the AE-0082 baseline (`.importlinter` untouched).
- Safety-net tests seed the carousel-origin blog row explicitly (AE-0127 shape) instead of relying
  on the removed auto-create, so they keep testing the unchanged read path.
