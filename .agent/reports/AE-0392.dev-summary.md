and regenerated the whole ~60 min content phase blind. Root cause: `snapshot._forbidden()`
folded every blocking `content_gate_validation` code (AE-0366 v3 rules) into the
forbidden-phrase list, and the revise template had no measurement for that reason. Finding: the
editorial graph state has no forbidden-phrase channel at all, so in prod `forbidden_phrase`
could only ever come from those folded-in validator codes.

1. **Reasons separated.** `GateSnapshot.forbidden_hits` = phrase hits + phrase scan only.
   New `GateSnapshot.quality_violations` (`QualityViolation`: rule, slide, locale, field,
   message, current text) read from `content_gate_validation` (content gate) or
   `presentation_validation` (design gate) by `domain/quality.py`. Policy: persona →
   `forbidden_phrase` → `content_quality` (new, `quality_constants.py`) → engine refusal;
   design: rules → `content_quality`, missing/rule-less report → `presentation_validation_blocked`.
2. **Feedback.** New prompt version `agents/prompts/autopilot/v2/revise_feedback.yaml` (v1 kept).
   Measured is never empty: phrases, `rule@slide` pairs (max 10, deduped), counts, blockers, or
   the engine code. For `content_quality` one line per failing slide (slide, locale, field,
   rule, message, current text ≤200 chars) and "fix only these slides".
3. **Repair before revise** (`application/gate_repair.py`, runner wiring, new
   `RunnerDependencies.gate_repair`). At content/design, for a revise *or* an escalation on
   `content_quality`/`presentation_validation_blocked`, the runner calls
   `GateRepairer.repair_gate` → `InProcessContentAutofixer` → editorial facade
   `run_gate_repair` → `OwnerAutofixService.repair_gate` (the same AE-0367 plan as the
   🛠 Fix button: fill features/summary points from the outline, `<strong>` balancing, proper
   nouns, `repair_casing`, bounded EN re-translate) over the **checkpoint** `localized_slides`
   (`load_gate_source`). Changed slides go through the reviewer-edit path
   (`apply_localized_slide_edits`: re-validate, sync slide_drafts/translations/content-gate
   report) and are written with `update_workflow_state` under the project lock + lock-version
   CAS; no rows, no re-render. Nothing to change → no write, no CAS. Then the gate is read again
   and decided by the same policy: clean → approve (no revision counted); left → revise with
   the remaining per-slide violations; lost CAS → wait for the next tick. Logs
   `autopilot_content_autorepaired` (fixed_rules, remaining_rules, next_action).
4. **Targeted re-draft:** not possible without engine surgery: a revise regenerates every slide
   (`generate_slide_drafts` over the outline) and structured feedback is final-review only.
   Fallback per brief: whole-phase revise with the specific violations; the content phase's own
   AE-0309 chain still re-drafts each blocking slide once. Per-slide revise = follow-up.
5. **Final gate:** final review stops for the owner (unchanged); AE-0367 Fix issues covers it.
