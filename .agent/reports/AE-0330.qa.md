### 1. Failed-phase → END routing

Verified sound. `route_after_gate`/`route_after_design` check `_phase_failed`
**first**, so failed wins even over a set approved flag; all five artifact gates map
`failed → END`. The content node is the only node with the
early-return-without-`interrupt()` pattern, so it is the only phase that can reach
the failed branch — the other four are defensive wiring. `current_phase` is
stamped to content on that path.

`route_after_final_review` and `route_after_hold` do **not** call
`route_after_gate` and can never return `failed`, so the absence of a failed
branch on those two edges cannot produce an invalid branch target
(independently confirmed by this session against the merged source).

`recursion_limit=100` was verified by the external reviewer against the
**installed langgraph 1.2.5**, not against the ticket's claim: the budget is
per-invoke relative to the resumed step, so a long-lived thread still gets 100
fresh supersteps per resume. It cannot be hit legitimately.

**MAJOR (external) — a silent no-op retry path survives the fix.**
`needs_gate_reopen`'s approved-field guard defeats the failed-phase reopen when the
approved flag is stale-True: a final-review/approved-hold send-back to content does
not reset `content_approved` (only the design node does), so a failed content regen
returns to END carrying `content_approved=True` + `phase_status=failed`; the retry
then evaluates the guard to False and issues a plain `Command(resume)` on a
finished graph — exactly the silent no-op this ticket set out to remove.
`test_failed_phase_at_end_is_reopened_on_retry` only covers
`content_approved=False`, so the gap is untested. → **AE-0343**.

**MINOR (external) — "every gated phase" is overstated.**
`test_every_gated_phase_maps_failed_to_end` enumerates 4 of 6 gated phases (images
is wired but unasserted), and the Gherkin scenario claims the failed edge is wired
on every gated phase, which is not literally true of `final_review`. Not a live
loop risk. → folded into **AE-0343**.

**MINOR (external) — `GraphRecursionError` has no handler in `backend/src`.** On
resume it is absorbed by a broad `except Exception`; on `workflow/start` it
escapes as a raw 500. Contained but untyped and unalerted.

### 2. Cache poisoning

**PASS, complete.** Independently confirmed by this session: the three
`_cache.set` call sites in `backend/src` are
`content_draft_agent.py:130`, `outline_agent.py:100`,
`source_synthesis_agent.py:58` — all parse-then-cache, no remaining path that
caches an unparsed reply. `_cached_raw` catches exactly the exception surface the
parsers raise (`extract_json`'s `JSONDecodeError` ⊂ `ValueError`), and
`ainvoke_json` raises before any `set()` on the failure path.

### 3. Retry logic (`agents/llm_json_retry.py`)

Empty-vs-malformed distinction is sound and **cannot loop**: empty → exactly one
re-roll then raise; malformed → exactly one repair round-trip then re-raise, with
the original error chained.

**MAJOR (this session) — the empty-response re-roll was not carried to
`source_synthesis_agent`.** The external reviewer recorded this agent as having
"equivalent behavior"; that is not accurate. `source_synthesis_agent` still uses
its own `_parse_with_repair`, which has **no empty-response branch**: an empty
reply falls into the repair round-trip, sending an empty `AIMessage` plus the
repair prompt — repairing nothing, burning a call, and then failing. The empty
reply is precisely the live failure AE-0330 was raised for, so the synthesis phase
is still exposed to it. → **AE-0346**.

**MINOR (external) — docstring contract not delivered.** `ainvoke_json` documents
that it raises `ValueError(ERR_INVALID_JSON)` after exhaustion, but the final
re-raise can be `TypeError` (valid JSON of the wrong shape), and
`phase_artifact_runner` catches only `ValueError` — that path escapes as a 500.
→ folded into **AE-0346**.

**MINOR (this session) — `cast(str, response.content)`** in `_ainvoke_once` and
`_arequest_repair` asserts a type the contract does not guarantee:
`AIMessage.content` is `str | list[...]`, and reasoning models can return content
blocks. A list would make `raw.strip()` raise `AttributeError`, outside the
declared `ValueError` contract. Latent, not observed. → folded into **AE-0346**.

**MINOR (external) — two more call sites in the same defect class** remain
unhardened: `editorial_distribution_generation.py:134` and
`nodes/content/core.py:59`. → folded into **AE-0346**.
