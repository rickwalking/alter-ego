## Developer Completion Report
Ticket: AE-0507
Status: Dev Complete

### Summary
"Create a palette with AI" (Pedro's decision): the New palette modal has a "Descreva a paleta" field. One
call on the fast LLM queue (`container.fast_llm_service()`, i.e. `LLM_MODEL_QUEUE_FAST` when configured)
returns up to three candidates through `POST /api/palettes/generate`. The server never trusts the answer:
strict hex, the palette name rules, sanitised keywords (brand keywords dropped, count/length capped), mode
derived from the background luminance, and every pair (slide ink/background, primary/background,
accent/background) brought to WCAG AA 4.5:1 by mixing the failing colour towards black or white. "Usar"
pre-fills the form; nothing is saved until "Criar". LLM errors, timeouts (90 s), non-JSON answers or no
valid candidate → 503 `palette_generation_unavailable` with a retryable message in the modal. 5/minute
rate limit per user (the route's dependency records the user id on the request state and the limit
keys on it; other routes keep the address key). The call is traced in Langfuse (phase
`palette_generation`, agent `palette_generator`, user id, content type `palette`).
