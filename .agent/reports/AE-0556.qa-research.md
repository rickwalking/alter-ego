# AE-0556 QA Research Pack

Basis: `origin/main...7f9b34bd6` (clean corrected head). Ticket: `.agent/tasks/AE-0556-carousel-generation-log.md`. ADR: `docs/decisions/0028-carousel-generation-event-log.md`.

## 1. Scope and acceptance

Durable, sanitized generation history for queued carousel work: run/phase timing, retries/recovery/manual reprocess, image/export, owner/admin pagination, 30-day retention, optional Langfuse and a live PT/EN workspace timeline. Synchronous initial `/workflow/start` is intentionally out of scope. AC1-AC9 and Gherkin are in the ticket and `backend/tests/features/carousel_generation_log_ae0556.feature` / `frontend/tests/features/create-generation-log-ae0556.feature`.

## 2. Data and deployment

`carousel_generation_events` has bounded fixed fields, flat JSON details, run/carousel cascade FKs and three indexes (`infrastructure/models.py`). Alembic `e7a91c4d2f60` chains from `d1b0cf9cd80d`; the existing generation-queue one-shot compiles and verifies the same DDL. The daily purge deletes events older than 30 days before existing run/log purges.

## 3. Privacy and recorder

`domain/generation_events.py` limits details to 4096 bytes and input to 64 fields/24 stored fields. IDs, sizes, providers, languages, models and codes have semantic constraints. `domain/failure_metadata.py` reuses main's AE-0553 `failure_metadata` and never reads exception text, SQL or parameters. `application/generation_events.py` binds one run scope, writes one sanitized row with a 100 ms timeout and emits one safe warning per failed write. Fixed project attribution can only be assigned once; later mismatches are ignored.

## 4. Queue and attempt fencing

`job_handler.py` and `job_tracker.py` preserve PR #291's attempt UUID CAS semantics. Phase failure events are emitted only after successful retry/dead-letter CAS. Manual `Dispatcher.kick()` now records `run_queued`; daily/manual recovery is visible through the existing dispatch pass. Run summaries are additionally filtered by authorized project or an originally unassigned autopilot run.

## 5. Notable steps

Phase artifacts/persona scores/content-gate counts, distinct workflow outcomes, image bridge lifecycle and missing results, per-slide provider outcomes, image reuse, PDF success/HD warning/standard-export/PDF-build failures are instrumented. No prompts, outputs, feedback, image bytes, SQL parameters or PgQueuer ids are accepted. Trace ID/URL comes from the pinned Langfuse SDK only when a span exists.

## 6. API

`GET /api/carousels/{project_id}/generation-log` uses the owner/admin management guard, not the assigned-reviewer guard. Default 50/max 200, `(occurred_at,id)` keyset, cursor anchors scoped to the project, invalid/foreign cursor 422. Responses exclude payload/raw errors. Tests cover owner/admin/assigned reviewer/anonymous/unknown, mismatch, limits, equal timestamps and insertion races on SQLite/PostgreSQL.

## 7. Frontend

Infinite cursor query invalidated by existing workflow state only; no new timer/stream. Native details/summary, newest run first, phase groups, attempt/outcome text, right-aligned durations, load more and trace links. Empty responses with one actual empty page are handled. Future run kinds/statuses have raw-code fallbacks. PT/EN parity covers all nested sections.

## 8. Regression evidence

Latest targeted evidence: 191 backend tests, 23 frontend tests; mypy 1202 files; import contracts/ratchet and integrity green; frontend lint/typecheck green. Earlier full backend capture was 26 PASS/0 FAIL/1 CI-only mutation SKIP. Full frontend capture had resource timeouts, not assertion failures; final rerun is pending. PostgreSQL tests include queue schema, retention, manual reprocess, migration and keyset/cascade.

## 9. Fixed findings from first research round

- Manual kick missing `run_queued`: fixed and tested.
- Stale attempt writing `phase_failed`: fixed by post-CAS failure recording and tested by attempt rotation.
- Fixed run attribution could migrate cross-project: fixed plus read-side correlation test.
- Real empty API page showed nothing: fixed with realistic page fixture.
- Related hardening: PgQueuer ids removed, semantic string constraints, safe warning assertions, missing image/export events, unknown UI states, equal timestamps, exact 30-day boundary, migration/cascade proof.
