# AE-0406 — Dev summary

T2 feature (ADR-0023). Branch `feat/ae-0406-pov-news-mode`, PR #124 (not merged: merging redeploys prod).

## What changed

New content mode **`pov_news`**: news analysis told through Pedro's point of view, with up to three **scout-verified quotes**. This implements spec v2 sections 1-6 and 9. Section 7 (assets) is phase 2.

**Intake (`POST /api/autopilot/topics`).**
- `pov_news` requires `thesis_draft` and ignores `pov_format`.
- Each quote is checked against the post text stored through `/x-signals`:
  - excerpt normaliser (NFC, curly quotes, whitespace runs, 600-character cut);
  - canonical X status URL, compared case-insensitively on the handle;
  - word limits.
- Five new reason codes. A quote problem, including a missing field, rejects only its topic. Unknown keys are still a 422.
- Every rejection has `index`, plus `field` when one field caused it.
- `pov_news` counts toward the daily cap only, not the weekly Radar IA cap.

**Storage.** `topic_candidates.quotes`, `carousel_projects.pov_quotes` and `carousel_projects.pov_sources` (Alembic `c4d5e6f7a8b9`, single head). **The prod columns were applied manually before merge (2026-10-16)**: prod has no `alembic_version` and migrate-on-deploy is disabled (AE-0207).

**Pipeline.**
- `pov_news` takes the whole POV path: thesis step, `pov_hook_v1`, slide-1 photo, validators and voice gate.
- It uses the new prompts in `carousel_pov_news/v1` (outline, hook, content, caption).
- Quote cards:
  - The model only picks a `quote_id`; code places the card verbatim, at most 2 per deck, `text_pt` on PT and `text_en` on EN. A retried slide drops its card.
  - Cards render with `insight_quote` plus an attribution row (initial circle, name, `@handle · X`, never a URL).
  - The autopilot content gate re-checks every card.
- Code appends the caption footer `Fontes: @handle, domain.com`.

**Telegram.** The thesis prompt reads "Ponto de Vista: Notícia".

**Frontend.** The new "POV: News" mode with i18n; the wizard hides the format picker.

The decisions and the content-mode branch list are in the ticket.
