## Findings and resolutions

| # | Severity | Finding | Resolution |
|---|---|---|---|
| 1 | BLOCKER | Re-pointing `down_revision` on merge with AE-0370 risks a split Alembic history | **Resolved (clarified + hardened).** Only a migration that has never reached `main` is ever re-pointed (repo practice, e.g. AE-0369's merge). Merge order is fixed: AE-0370 first; this branch then merges `main` and re-points its first migration onto AE-0370's head **before** its PR merges. The `migrations` gate (upgrade/downgrade + single head) runs on the merged tree. The hand-applied prod SQL uses `ADD COLUMN IF NOT EXISTS` / `CREATE TABLE IF NOT EXISTS`, so applying it twice or in either order is safe; `alembic_version` is stamped to the final head. Plan §D3 and §8 updated. |
| 2 | WARN | Rollback breaks POV projects (old code trims to 7 slides) | **Accepted, documented.** Old code would render a POV project as a garbled 7-slide Radar IA deck. POV projects stay private until approved, and the contract/prompt files are immutable, so redeploying restores them. Plan §8 now says: after a rollback, POV projects created in the window must be regenerated after the re-deploy; no data migration (nothing is lost, columns stay). |
| 3 | WARN | Normalizer silently falls back to the 7-slide path when the LLM omits one role | **Fixed in design.** Roles never come from the LLM: right after generation, the mode-aware generator stamps roles and slide types **by position from the project's expanded contract**, so a POV/v4 outline always carries a complete role set before any normalization. A length outside `[min, max]` is trimmed to max / reported as `slide_count_invalid`; it can never silently take the legacy path. Plan §D1 updated. |
| 4 | INFO | Thesis edited between outline and content phases | **No change needed.** POV inputs are create-only (`CarouselProjectUpdate` only allows title/subtitle/blog/caption), exactly like topic/audience today. `hook_text` is deliberately editable (the hook picker) and is read only by the content phase. Plan §D4 states it. |
