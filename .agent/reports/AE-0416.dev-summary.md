## What changed

1. **PT blog body**: `build_blog_markdown_from_long_form_notes` no longer adds the English
   research summary; `editorial_distribution_pack` passes the summary to the EN build only.
2. **Publish viewer**: `viewerSlidePaths` builds one `slide_N.jpg` preview URL per workflow
   slide (`resolveLocalizedSlides`), with the design tokens as the fallback; unrendered slides
   show a placeholder; the EN tab uses `title_en` in the alt text and notes that the Instagram
   caption is PT only.
3. **Workflow board**: `BOARD_COLUMNS = [*BOARD_PHASES, "rejected"]`; rejected projects go to
   the last column with their real phase; the frontend localizes the column and badges each card
   with that phase. Golden snapshot updated (+ empty `rejected` column).
4. **Locale**: `resolveLocale` / `getRequestLocale` (cookie → Accept-Language → default)
   replace six cookie-only copies.
5. **Blog dashboard paging**: 24 per page via limit/offset; status and search are API filters;
   pager; dates follow the dashboard language. `filterBlogPosts` removed (dead).
6. **Dead code**: `RichTextEditor`, `RichTextEditorProps` and the `@tiptap/*` packages removed.

Tests that asserted the old PT intro (`test_blog_composition`, AE-0347 title test) now assert
the new behaviour. #131's `/blog/[id]` page test mock gained a `headers` stub.
