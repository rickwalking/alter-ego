## Developer Completion Report

### Summary
A rubric could be saved with zero criteria: the form schema had no minimum and the API defaulted
`criteria` to `[]`. Now `QualityRubricCreate.criteria` is required with `min_length=1`,
`QualityRubricUpdate.criteria` keeps `None` = "unchanged" but rejects `[]`, and the form schema has
`.min(1)` with the field message "Adicione ao menos um critério." under the criteria section.

### Acceptance Criteria Implemented
- [x] Form blocks a rubric without criteria with the field message and sends nothing —
      `blocks a rubric without criteria until one is added`, `requires at least one criterion`
- [x] POST with `criteria: []` or without criteria → 422, nothing stored — `test_create_without_criteria_is_rejected`
- [x] PUT with `criteria: []` → 422, stored criteria kept; PUT without criteria still updates —
      `test_update_to_no_criteria_is_rejected`, `test_update_without_criteria_keeps_them`
