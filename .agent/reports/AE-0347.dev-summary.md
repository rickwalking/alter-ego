# AE-0347 — Dev Summary

**Ticket:** carousel blog body is an H1-only stub; non-public carousels leak publicly
**Branch:** `feat/carousel-blog-body-fix` (worktree off `origin/main`)
**Tier:** T2

## What broke

Prod project `dcaa5fef` (blog row `9817ec2b`): the stored blog is one line,
`# <raw English topic>`, in both PT and EN. All 15 most recent carousel-origin
`blog_posts` rows (2026-06-18 → 2026-09-14) have 14–137 char bodies and zero
`##` sections. Four independent defects:

1. `carousel/v3` and `v4` `content.yaml` never asked the model for
   `long_form_notes` — the field AE-0032 made the blog composer depend on.
2. `phase_artifact_runner` read `state["research_summary"]`, which nothing
   ever wrote (research lives in `research_findings`).
3. The editorial path never set `title`/`title_en` → H1 = raw topic, both languages.
4. The dual-write stamps carousel blogs `published` at compose time and the
   public routes filtered on status only → blogs of `is_public=false` carousels
   were listed and served (200) on `/api/public/blog-posts`.

## What changed

- **`carousel/v5/content.yaml`** (new version folder, v4 kept): the return
  contract is `{draft_text, confidence_score, sources_used, icon_name?, long_form_notes}`
  with an explicit 2–4 paragraph prose spec. `ContentDraftAgent` renders v5,
  sanitizes notes case-preservingly at the source, and logs one
  `content_draft.long_form_notes_missing` warning per slide when the model omits them.
- **EN translation** (`PROMPT_EDITORIAL_SLIDE_TRANSLATIONS` + payload/parser)
  carries `long_form_notes`; a draft without `slide_index` is keyed by position.
- **`research_summary_from_findings()`** joins de-duplicated per-source
  summaries; the runner feeds it from `research_findings`.
- **`_ensure_blog_titles()`** derives PT/EN titles from the slide whose index is 1
  (its EN heading for `title_en`) only when unset.
- **`public_blog_visibility_clause()`** (publishing facade) gates carousel-origin
  rows on the parent carousel's `is_public`; both public routes use it (count,
  list, detail). Read-time gate → fixes already-stamped prod rows without a migration.
- **anyio 4.13.0 → 4.14.2** (pip-audit was red repo-wide on two advisories).
