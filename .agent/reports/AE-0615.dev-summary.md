## Developer Completion Report
Ticket: AE-0615
Status: In Development (full gate: lead's heavy slot)

### Summary

The autopilot's cover generation succeeded during research, but the background selection waits for a pause
the drive never shows: the runner resumes each gate in the same step it reads it. The first settled state
the poll saw was the final review, which is a permanent `carousel_completed` skip. So the first review went
out with the default slide 1. Now, at each gate and before it resumes, the runner asks for the carousel's
succeeded autopilot cover. The existing selection runs once without waiting, with the same checks and write
(the generation's own asset, the owner-choice baseline, the project lock and the lock-version CAS), before
the finalize render. When slide 1 takes the cover, the step ends and the gate is read again at the new lock
version. A conflict is tried again at the next gate. Consent gates it. A crash is logged. No validator,
gate, limit, timeout, poll window or consent rule changed.

Second prod path (`d418daf9`): a deploy between the cover's success and the next gate lost the in-process
selection. The gate now reads everything from the database. That is the carousel's newest succeeded
generation that has a row in the new table `carousel_cover_autopilot_baselines`, together with that row's
slide 1 cover fields from scheduling time. No process memory is involved, so a restart changes nothing and
an owner's pick made after scheduling is still refused. The table is additive (revision `b2c3d4e5f6a8`) and
is created by the startup `create_all`, so no deploy one-shot is needed.

### Acceptance Criteria Implemented

- Drive straight through to the final review: `slide_cover` = the generated asset, kind `ai_image`, before
  the final review (lock version 3 → 4, one write).
- The owner's photo rebound before the gate, or a cover chosen before the job, is kept (`manual_choice`,
  `owner_cover`).
- No consent: nothing written. Failed generation: slide 1 untouched, never remembered.
- A held lock at research: the cover lands at the outline gate. Crash: logged, the drive resumes.
