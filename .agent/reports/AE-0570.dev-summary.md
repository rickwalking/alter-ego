# AE-0570 dev summary — Workflow board accessibility

Ticket: `.agent/tasks/AE-0570-board-accessibility.md`

## What shipped

Split PR D of the AE-0557 board critique (P2-1, P2-2, P2-3 and the "Sam"
persona flags), on top of the merged AE-0568 (layout) and AE-0569 (discovery)
splits.

- P2-2 keyboard: roving tabindex across board cards (one tab stop; Up/Down
  within a column, Left/Right to the same index in the adjacent non-empty
  column clamped, Home/End, Enter opens, `scrollIntoView` nearest), in the new
  `use-board-roving-focus.ts` hook; cyan focus ring on the card links; column
  card lists announce their item count (`labels.columnCount`).
- P2-2 nesting: "Novo carrossel" / "New carousel" is now a single `next/link`
  styled with `neonButtonVariants` (no more `a > button`).
- P2-3 segmented control: `WorkflowViewSwitch` (radiogroup, `aria-checked`,
  arrow keys, one tab stop) persisted as `?archived=1` via `router.replace`
  keeping the other query params; the archived top bar title reads
  "Arquivados" / "Archived". `page.tsx` slimmed to a Suspense shell; the top
  bar + view moved to `workflow-board-chrome.tsx` and `workflow-board-view.tsx`
  (page.tsx was at 198/200 lines).
- P2-1 overflow menu: `CardArchiveAction` is now a 28px `⋯` trigger
  (`aria-label` "Mais ações: {title}" / "More actions: {title}", outside the
  card link) opening a fixed-position `role="menu"` (not clipped by the column
  scroll container). "Arquivar" keeps the existing confirm step inside the
  menu; the refusal reason renders once as disabled menu text; nothing renders
  for `archiveRefusal === "published"` or `canArchive === false`; archived
  cards offer "Restaurar". Escape closes the menu and returns focus to the
  trigger; outside mousedown closes.
- i18n: `workflow.board.columnCount`, `workflow.board.viewGroup`,
  `workflow.archive.menuLabel` in pt/en; `workflow.board.newCard` copy changed
  to "Novo carrossel" / "New carousel" (Pedro's brief).

## Failing tests first

`.feature` scenarios, then failing tests (menu interaction rewrite of
`card-archive-action.test.tsx`, radiogroup/URL tests in `page-archive.test.tsx`

menu form (disabled card-level button with accessible description became a
