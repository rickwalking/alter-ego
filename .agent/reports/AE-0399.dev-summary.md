# AE-0399 — Dev summary

Hotfix (T1, owner fast path). Branch `fix/ae-0399-model-queue-breaker`.

## What changed

- **Model queue:** each role (`LLM_MODEL_QUEUE_FAST` / `_REASONING`) is now a queue of models behind per-model circuit breakers.
- **Failure classes:**
  - fatal and quota failures skip the model at once, with long cooldowns;
  - transient failures retry with backoff and open the breaker after 3 in a row;
  - 429 rate limits are debounced;
  - empty answers are re-rolled;
  - bad JSON moves on to the rest of the queue.
- **OpenCode sidecar:** an isolated container serves the free DeepSeek model.
- **Alerts:** breaker changes go to a send-only Telegram alerts bot.
