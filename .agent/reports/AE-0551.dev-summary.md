### Summary
Pedro, 2026-10-25: "Allow me to create images without any other background by giving tips on the word." and
"Upload images to be sent, not just select existing images."

- Backend: `POST /api/carousels/{id}/cover-generations` takes 0-3 `photo_ids` (absent means none). With no
  photo the route renders the new `cover_generation/v1/generate` prompt and the bridge sends the contract §2.1
  text body (no `operation`, no `image`; size 1024x1536, content type `carousel_cover`, same model and
  editor). Everything else is the AE-0508 path: confirmation, owner and POV only, caps, attempt ceilings,
  one pending per carousel, the log line with the prompt hash and `photo_count` 0. No schema change.
- Frontend: the "Gerar capa com Grok" panel renders with an empty library and needs only a prompt. "Enviar
  foto" calls the page-composed library upload (`useUploadCreatorPhoto`, role `hook`), refreshes the cover
  options and ticks the new photo while fewer than 3 are ticked; "Gerar capa" is held while it uploads. A
  refused file shows the wizard's upload sentence. The no-photo confirmation says only the description is
  sent. pt/en copy; the accepted image types are one shared constant.
- Docs: bridge contract §2.5, ADR-0027 follow-up line, prompt README.
