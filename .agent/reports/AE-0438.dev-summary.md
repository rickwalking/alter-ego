## What changed

- **Versions (F-05).** `blog_version_history.append_version` never appends an empty snapshot
  (`is_empty_document`: no cover/quality, no non-empty heading/body/image, empty translations).
  The generation's first write therefore leaves `version_history` empty and the FIRST appended
  entry (the next write's pre-state) is the first stored AI draft — restoring it validates.
  Restoring a pre-fix empty snapshot answers 422 `blog_version_empty`.
- **Operator command.** `python -m rag_backend.scripts.blog_empty_versions --count / --apply /
  --verify`: read-only count of posts whose history holds empty snapshots; `--apply` drops them,
  renumbers 1..N (idempotent, batched, `pg_advisory_xact_lock`); `--verify` exits non-zero while
  any remain. The orchestrator runs it, not this PR.
- **Rewrite (F-08).** `BlogPostAIService.rewrite_section` passes a no-heading instruction to
  `PersonaAgent.enforce` and `strip_heading_echo` removes a leading `**H**` / `# H` / plain echo
  (normalized: case, markers, whitespace) from the returned body.
- **Errors (F-11).** `BLOG_EDITOR_ERROR_CODE_KEYS` maps backend `detail` codes to specific
  pt/en copy (`errors.code.*`); a shared `EditorErrorNotice` renders them AT the failing action:
  ReviewBar, VersionHistorySidebar, per-slot controls and the top banner. `useBlogReviewActions`
  keeps its own error state; `handleRestore` returns the error to the sidebar.
