# AE-0405 — Dev summary

Hotfix (T1, owner fast path). Branch `fix/ae-0405-content-feedback-lifecycle`, based on
`docs/ae-0405-content-feedback-ticket` (PR #122, superseded by this PR). Brief:
`~/alter-ego-wt/briefs/ae-0405-brief.md`.

## Root cause (two layers)

1. **Notes accumulate.** `persist_phase_feedback` appended every content note and nothing
   cleared it, and `PhaseArtifactRunner` fed all of them to any content re-run, so any re-run
   with notes regenerated.
2. **The interrupted pass is never committed.** A real-graph experiment (in-memory
   checkpointer, counting runner) showed that LangGraph replays the whole content node on every
   resume, and that the return value of a node that interrupted is discarded. The content ensure
   (which can regenerate every slide) therefore ran again on approve, on revise and on an
   edits-only resubmit. With notes it regenerated again and committed drafts nobody had reviewed.
   This is the 98a2e2f0 symptom: hand-fixed slides 3 and 8 were replaced on approval. Clearing
   notes inside the ensure alone would not help, because that clear is also discarded at the
   interrupt.

## What changed

- **Lifecycle** (`content_feedback_lifecycle.py`, constants `domain/constants/content_feedback.py`):
  active texts stay in `phase_feedback` (API shape unchanged). Tagged entries (`source`
  human/autopilot, `added_at`) go in `phase_feedback_notes`. Consumed notes go in
  `phase_feedback_history` with `status` applied/dropped/migrated and `settled_at`;
  `feedback_history(state, phase)` is the query (AC6).
- **Applying.** The content ensure consumes the notes it regenerated with. A failed
  regeneration (invalid JSON) keeps them.
- **Durable parked review.** The content node puts that pass's artifact updates on the interrupt
  payload. `CarouselWorkflowEngine` (after start, resume and continue_pending) saves them to the
  checkpoint with `content_artifacts_parked=True` and `content_approved=False`
  (`carousel_content_park.py`), then re-parks with `ainvoke(None)`, because the write drops the
  pending interrupt. On resume the replay reuses the saved artifacts: no ensure and no LLM call.
  The reviewer's edits apply on top, and the node finishes with the marker reset.
- **Stale approval.** Resetting `content_approved` closes a latent hole: after a final-review
  send-back it stayed True, and any checkpoint write at the parked content review routed past the
  content gate. That includes the existing `persist_phase_feedback`.
- **Autopilot.** `editorial_driver` sends `structured_feedback.feedback_source=autopilot` with
  its gate feedback, and `prepare_resume_workflow` files the note tagged. An active autopilot
  note is `dropped` when the content gate is approved.
- **Migration on read.** On every resume, `prepare_resume_workflow` settles legacy untagged
  content notes to `migrated`, unless the content phase is `failed`.
- **State schema.** The three new fields are in `CarouselWorkflowState`; LangGraph drops keys
  outside the schema.
- **Docs.** `docs/backend/content-feedback-lifecycle.md`, linked from `backend/CLAUDE.md`.

## Interaction with AE-0401 / AE-0403 / AE-0404

- **AE-0403 "Enviar correções manuais"** (an edits-only revise) now applies the edits on the
  saved artifacts. The content node then re-enters, and its ensure runs with no notes and the
  drafts present, so there is no regeneration and the fail-closed chain re-validates the edited
  drafts (AE-0366 writes the edits back to the drafts). Test: byte-for-byte equal and the
  drafting spy is not called.
- **AE-0401 model fixes and the gate repair** write the checkpoint through
  `update_workflow_state` while the review is parked. The replay reuses the checkpoint as
  written, so the fixed slides are what the approval commits.
- **AE-0404** (merged into main during this work) touches no file in this change; merged with no
  conflicts.

## Decisions (nobody to ask; also in the ticket's Decision Log)

- **Fix shape.** Save the parked pass instead of splitting the content node into generate and
  review nodes. A split changes the graph topology under live checkpoints and every send-back
  route: too wide for a hotfix.
- **Payload transport.** The artifacts travel on the interrupt payload (only the engine reads
  payloads). The engine re-parks right after the write so `get_state` keeps reporting
  `awaiting_human` and `is_parked_before_node` does not treat the review as a dead run.
- **Legacy migration** runs on resume: untagged notes predate the last regeneration unless the
  phase failed.
- **No API change.** AC6 is served by `feedback_history` over checkpoint state; the OpenAPI and
  Zod schemas are unchanged.
- **400-line rule.** `carousel_workflow_nodes.py` was already 520 lines and is now 560. Moving
  the content node to its own module was tried and reverted: it adds an agents→application import
  pair, which the import contract, the arch ratchet and the integrity gate block.
  `phase_artifact_runner.py` did not grow (644).
- **Out of scope, reported.** A send-back from the approved-hold park goes through
  `persist_phase_feedback` → `update_state` with `as_node` inferred as `approved_hold`. That
  completes the hold node and the graph ends, so the send-back is lost. This predates the change
  (the documented `as_node` footgun). Follow-up ticket recommended.

  edits-only, autopilot, approval resume, migration, failures).

  regeneration.

  the prod 98a2e2f0 legacy state, persistence and `parked_content_updates`.
