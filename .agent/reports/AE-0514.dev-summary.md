## Summary

The /admin users area now uses the dashboard app shell (`NeonAppShell`, extracted from the dashboard layout and
shared by both layouts): sidebar drawer below lg with the EN/PT switch, dark neon tokens. Every user dialog is built
on `NeonModal` (new optional `role` and `closeLabel`, `useId` title id, scrolls inside the viewport). Errors are
mapped to pt/en messages by HTTP status + a stable `code` that the backend now adds (additively) to four error
bodies; the English `detail` is never shown. Users stack as cards below 768 px; the table scrolls in its own box.
