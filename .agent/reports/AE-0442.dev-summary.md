### Summary
Fixed Langfuse trace I/O and naming for the carousel/blog workflows. Phase
traces now record sanitized input and result/error output on both the root span
and the trace, set `session_id`, and flush at the phase boundary. Generations
get a descriptive `run_name` from the active phase plus an optional detail
instead of `ChatOpenAI`. `create_workflow_trace` opens/ends a named span with
I/O and reuses an active phase span, so nested helpers no longer clobber
project/user/agent metadata. Human review events now live in a named
`workflow_review` trace instead of becoming orphan unnamed EVENT traces.
Background blog/resume runners flush at run end through application-layer
wrappers, preserving the DDD import boundary.

### Mutation baseline hang (2026-10-21)

The mutation gate baseline timed out because `flush_workflow_traces` called
`client.flush()` on the resume task while the OTLP exporter retried an
unreachable Langfuse host. Flushes are now coalesced onto one daemon worker
(`schedule_flush`); callers never wait, errors are logged, and no client is
created when tracing is unconfigured. Per-phase flushes and
`create_workflow_trace` use the same scheduler. Added a resume integration test
with a blocking exporter flush (completes in <3s) and a unit test that the
flush request returns in <0.5s; flush assertions poll the worker. Reproduced
the exact baseline test locally (passes).

### CI regression fix (2026-10-21, commit 4a297dcc)

The first CI run exposed 15 integration failures caused by old test-double
signatures (`blog_phase_trace` and the autopilot spy rejected `trace_input`),
plus the intentional `workflow=editorial_7_phase` metadata key now merged into
research phase traces. Fixtures and expectations were updated, and all tracing
side effects are now best-effort: span open/close, updates, propagation,
events and flush swallow SDK errors (logged) so Langfuse cannot change a
workflow outcome. Body exceptions still propagate. The feature gained two
safety scenarios.

Local verification after the fix: blog generate 15 passed, blog rebuild 9,
phase traces 4, autopilot runner start 1, trace/fake unit suites 43.
CI `backend / Test & Coverage` passed in 11m6s on `4a297dcc`. The separate
`backend-gate` job hung after 2% of tests and failed at 21m32s without a test
failure summary; the fresh CI run is the arbiter.
