## What changed

**Part 1, validators.** 11 blocking copy-hygiene rules on `pov_hook_v1` and
`hero_lower_third_v4`, PT and EN, heading/body/items (`presentation_copy_rules.py`,
detectors in `copy_hygiene_text.py`): `structured_payload_in_copy`, `markup_leak`,
`emphasis_unbalanced`, `assistant_chatter`, `placeholder_text`, `encoding_garbled`,
`copy_truncated`, `body_too_short`, `wrong_language`, `repeated_text` and (addendum 5)
`structured_item_split`. A safe deterministic repair (`copy_hygiene_repair.py`) runs in the
generation-time review repair (first, so a JSON blob is read before a length trim cuts it) and
in the owner/gate autofix plan. On the reconstructed 9-slide prod deck the clean deck passes
every rule and the broken deck (fenced blob slide 3, `## Checklist para salvar` slide 8) is
repaired back to the clean deck exactly, with no model call.

**Part 2, autopilot model fix.** `SlideAutofixStep` runs after the AE-0392 gate repair
(composed inside `GateRepairStep`). A gate still failing on `content_quality` or
`persona_score_below_threshold` at the content/design gate calls the editorial facade
`run_slide_fix` → `SlideFixService`: failing slides (blocking violations, or a per-slide
voice score under 70 at the content gate) are rewritten in parallel
(`CONTENT_DRAFT_CONCURRENCY`) on the fast role, at most `AUTOPILOT_AUTOFIX_ATTEMPTS` (3)
attempts each, prompt `agents/prompts/carousel/v1/slide_fix.yaml`. Fixed slides are written
once via `apply_localized_slide_edits` + re-scored `persona_scores`, under the shared lock +
lock-version CAS (extracted to `owner_autofix_lock.py`). Clean → approve; otherwise escalate
with the slides listed (state-changed event `detail` → Telegram). Per-attempt log
`autopilot_slide_autofix`; Langfuse `phase=autofix`, `agent_name=slide_fixer`.

## Addendum

1. `<strong>` (EN) and `**bold**` (PT) are legit: `markup_leak` flags only other tags; the
   repair keeps `<strong>`, turns `<b>` into `<strong>`. The rubric text was put back.
2. Hook heading == body: `heading_repeated_in_body` already blocks it (test added); the fix
   prompt asks a hook for a DISTINCT sub-hook.
3. EN colon casing: `repair_colon_case_en` lowercases the word after a mid-sentence colon
   (proper nouns, "I", acronyms, camel case kept). I could not find a code path that
   capitalizes after a colon (`capitalize_sentence_starts` splits on .!? only), so the repair
   undoes it wherever it came from (model or repair).
4. Repair no-op loop: with the slide fixer, a no-op goes to the model fix and then escalates;
   an escalated run is no longer picked by the runner. Scenario + test
   `test_no_progress_escalates_and_never_loops` (2 ticks: 1 no-op, 3 attempts, 1 escalation).
5. Fenced blob items: the structured-payload repair keeps whole `summary_points` /
   `features` / `actions` items from the blob. The "Comece com dois ou" split came from
   `owner_autofix_fill._split_on_words` (outline fill): it now splits at a comma first and
   never ends a title on a connector. New rule `structured_item_split`.

## Decisions (nobody to ask; recorded here)

- **Contracts edited in place** (`pov_hook_v1`, `hero_lower_third_v4`) despite the
  "never modify a policy file" README rule: the brief names the POV contract, in-flight
  autopilot carousels must get the rules, and nothing checks the stored checksum. "The default
  policy" read as v4 (the other creation-time contract); v1-v3 untouched (legacy semantics).
- **`copy_truncated` exempts intro and CTA** (the hook sub-line and the CTA are fragments).
  **`body_too_short`** = content slides only, 8 words, waived when 3+ complete features carry
  the copy. Rehooks under 8 words now get a model fix.
- **Inline backticks** are flagged per the brief and addendum, although
  `_shared/text-formatting.md` documents `code` pills; the repair just removes the backticks.
- **The model fix runs only when the fixer is wired** (`RunnerDependencies.slide_fix`; the
  worker always wires it). Without it the AE-0392 revise path is unchanged, so its tests stay.
- **Partial success is persisted**: slides that pass are written, the others keep their copy
  and are listed in the escalation.
- **No model call under the lock**; the CAS at write time is the idempotency guard (a crash
  before the write writes nothing; a lost CAS logs `autopilot_slide_autofix_conflict` and the
  next tick re-reads).
- **Voice re-score** stores `{**previous, overall: new}` (the sub-scores are not re-derived),
  only when the slide's text changed and the deck was scored.
- **Per-attempt logging happens in the autopilot** (it has the run id), from the attempt
  records the facade returns.
- **`AUTOPILOT_AUTOFIX_ATTEMPTS` is not added to deploy.yml / compose**: it defaults to 3 and
  the env-parity gate does not require it (no prod `.env` rewrite needed).
- **Prod slides**: the prod copy is not readable from this machine; the 9-slide fixture is
  reconstructed from the evidence (budgets, roles, emphasis, proper nouns, numbers).
- Files over 400 lines: `presentation_validation.py` (412 → 414) and `messages.py`
  (397 → 402) were already at the limit; `runner.py` stays under (389) by moving
  `GateRead`/escalation/ready-notice helpers to `gate_read.py`.
