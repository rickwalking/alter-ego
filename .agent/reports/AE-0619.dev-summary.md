# AE-0619 — dev summary

## Change

Tests only, in `backend/tests/integration/carousel_consolidation/`. Nothing under `backend/src` changes. Root causes
and decisions are in the ticket.

1. `EventConnections` (moved to `event_connections.py`) installs the test's SQLite trace hold inside each shielded
   connect, so every recorder connection is held from the start. The old lazy arming keyed by `id()` let a reconnect
   reuse a freed wrapper's address, run its insert unheld and commit it (#358).
2. The suite's SQLite file runs in WAL mode. A write cancelled during its run lookup leaves a cursor alive past its
   connection's close; in rollback-journal mode its read lock failed the workflow's commit with
   `database is locked` (#359).
3. The insert test also asserts that no held recorder statement completes. A new test,
   `test_a_cancelled_event_read_does_not_lock_the_workflow`, cancels every run lookup with the collector off.

No limit, budget, timeout, skip, retry or sleep changed.
