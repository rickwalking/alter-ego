### Summary
CHAT-20 from the /chat QA. A conversation owned by a signed-in user is reachable only by its owner and by admins.
Everyone else, signed in or not, gets the same 404 `Conversation not found` that an unknown id gets. This covers
stream, non-stream chat, get, messages, generate-title, delete and publish-chat. The list stays filtered by owner.
On the stream, an unknown id is now a 404 before the stream starts. Before, it was a 200 with an SSE `error` event.
Anonymous conversations stay open to the anonymous stream; binding them to their `anon_token` is the next PR (1b).

### Acceptance Criteria Implemented
- [x] Anonymous stream/chat into a signed-in user's conversation: 404, nothing persisted.
- [x] Another user on every conversation endpoint: 404 "Conversation not found".
- [x] Owner and admin: 200/204 on stream, chat, get, messages, generate-title, delete; anonymous reads stay 401.
- [x] Unknown and foreign ids return the same 404 body on the stream.
- [x] Anonymous visitors still stream into anonymous conversations.
