### Summary
The public chat reads public knowledge only. An anonymous conversation's Alter-Ego agent searches the
`public` namespace and its `list_documents` tool lists public documents only; a signed-in user's
conversation (the owner's dashboard chat) keeps `personal` + `public`. The scope is picked from the
conversation's `user_id` on both the streaming route and the non-streaming messages route, and an agent
built without a scope reads public knowledge only.
