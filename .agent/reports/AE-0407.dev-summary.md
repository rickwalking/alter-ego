## What changed

1. **Escalation to the reasoning model.** `fix_slide` runs stages: up to
   `AUTOPILOT_AUTOFIX_ATTEMPTS` (3) on the fast rewriter, then up to
   `AUTOPILOT_AUTOFIX_ESCALATION_ATTEMPTS` (new, default 2, `ge=0`) on the reasoning rewriter
   (`build_chat_model(settings, LLM_ROLE_REASONING)`, not built when the setting is 0). The
   attempts are numbered 1..5; `FixAttempt.model_role` goes through the facade report and the
   autopilot record into `autopilot_slide_autofix` (`model_role`). The escalation text counts
   every attempt ("(5 fix attempts)"). The setting is wired worker → tick config → autofixer
   → `SlideFixRequest` → `SlideFixSettings`, named on deploy.yml (`vars.`, default '2')
   and docker-compose.prod.yml (`:-2`), and is in the autopilot-env parity gate with a
   numeric-default rule (the seeded-violation tests prove it fires).
2. **One 0-100 scale on every read.** `domain/persona_score.py` (`stored_overall`,
   `lowest_overall`, `on_hundred_scale`) is used by `slide_fix_targets`, the autopilot
   snapshot and `validate_content_approve_persona_score`. (0, 10] reads x10; 0, missing or
   unreadable reads unscored. `_parse_evaluation_response` scales `overall` on its own.
3. **Judge failures are not verdicts.** `application/services/carousel/persona_judge.py`
   `judge_voice`: error, 120 s timeout, 0 or no `overall` → retried once, then None
   (`persona_judge_failed` with attempt, reason, unscored). The slide fix keeps the previous
   score and adds no `voice_score_low`; the content phase leaves the slide out of
   `persona_scores`. 0.0 is never written.
4. **Casing markers.** `slide_fix_casing.clear_rewritten_casing_markers`: the marker of a
   field the model's answer set (and that landed in the candidate) is dropped when the model's
   own text passes the live sentence-case check, before the deterministic repair.
5. **Handles and URLs.** `sentence_case._lowercase_letter_at` skips a start right after `@`
   or at `http://`, `https://`, `www.`.
6. **Frontend.** `insight` renders as a read-only quote card (`<figure>`, quote, name,
   `@handle · X`, no URL) in both locale columns; en/pt keys; malformed → JSON fallback.

Superseded rules (tests and scenarios updated, see the ticket Decision Log): a missing or
unreadable `overall` was 0 / fail-closed (AE-0364 QA r1 B1); AE-0401's flow now counts 5
attempts.
