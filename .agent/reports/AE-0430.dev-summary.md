## What changed

- **A, targeted gate repair** (`content_gate_repair*.py`, prompt
  `carousel_gate_repair/v1/field_repair.yaml`):
  - Runs when the content ensure ends blocked. Only the failing fields go to the fast
    model, each with path, current text, exact budget, problems, slide heading and PT
    source.
  - Answers are patched in by path, then re-validated. At most 2 rounds and 40 fields per
    round. No truncation, never raises.
  - Write-back goes through `apply_localized_slide_edits`.
- **B, revisions**: the regeneration gets the owner's note plus one line per blocking
  violation; the repair runs after it. The note is `applied` only when the visible copy
  changed, otherwise `unchanged`.
- **C, translation shape**: v8 translation prompt plus structure carry-over
  (`editorial_translation_structure.py`). A residual mismatch is filled from PT and
  translated by the repair loop.
- **D, editor**: `mirrorLocaleStructure`. The editable column shows every structured field the
  other locale has (EN TL;DR included); an edit creates it.
- **E, labels**: `**PT**`/`**EN**` are locale section headers in the scaffold recovery; an EN
  payload built from the draft takes the EN section heading.
