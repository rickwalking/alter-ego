## What changed

1. **Upload** `POST /api/autopilot/assets` (`modules/autopilot/api/assets.py`, nested in the
   autopilot router: same API key and shared rate limit). Form rules in
   `domain/cover.py`, image rules in `application/services/carousel/cover_asset_validation.py`
   (magic bytes, 5 MB, ai_image 4:5 centre crop ≥1080×1350 then scaled to 1080×1350,
   screenshot ≥600 px wide, 4096 px / 16 MP, WebP re-encode). Stored through the editorial
   facade seam (`modules/editorial/infrastructure/carousel_cover.py`) as a creator asset with
   role `cover` (hidden from the owner's library) + a row in `autopilot_cover_assets`.
2. **Topic field** `cover.asset_id`: per-topic rule last in `domain/intake_rules.py`
   (`cover_asset_unknown|expired|used`, `cover_source_invalid`), one use per asset (also
   within a batch); the stored topic claims the asset. `domain/intake.py` split
   (`intake_proposal.py`) to stay under 400 lines.
3. **Owner choice**: cover preview photo + toggle on the thesis prompt and every review
   (`domain/cover_offer.py`, `application/cover_actions.py`, `ap:cv:` / `ap:cvoff:`).
   Thesis: CAS on the run (`autopilot_runs.cover_chosen`); the runner puts the chosen cover in
   the spec and the editorial ACL stages it at create. Review: `owner_cover` rework →
   `rework_step._cover` → `switch_slide_cover` (stage, lock-version CAS write of
   `carousel_projects.slide_cover`, republish) → normal final-review stop sends a fresh review.
4. **Render**: `ai_image` replaces the POV hook photo / Radar IA intro artwork; `screenshot`
   uses the new `cover_card` strategy + CSS; a missing staged file raises
   `HookPhotoError(slide_cover_unreadable)` (`strategies/photo_errors.py`).
5. **Sweep** of unused covers > 6 h on the Telegram notify tick (`application/cover_sweep.py`,
   `bootstrap_telegram.py` split out of `bootstrap.py`).
6. **Schema**: Alembic `d5e6f7a8b9c0` (idempotent). Manual prod SQL is in the PR body.
7. Docs: ADR-0024 (proposed), ADR-0020/0023 links, root `CLAUDE.md`, `grokbot-autopilot.md` §5.8.

Existing tests updated for real behaviour changes: single-head migration tests (new head), strategy
counts 12 → 13, the strategies golden snapshot, the route snapshot (+`POST /api/autopilot/assets`),
and one import path (`bootstrap_telegram`).
