### Summary
The "Criar usuário" password input was `type="text"`, so the new user's password showed in clear. A new
`PasswordInput` (admin components) renders a masked `new-password` input with a labelled show/hide toggle
(`type="button"`, `aria-controls` the input, name "Mostrar senha" / "Ocultar senha", 44 px wide), and
`CreateUserDialog` uses it. A typed password is never echoed in the dialog.

### Acceptance Criteria Implemented
- [x] Masked by default, `autocomplete="new-password"` (`renders a new-password input that is masked`).
- [x] Labelled toggle shows and hides the value (`shows and hides the typed password on demand`).
- [x] The toggle never submits the form and names the input it controls.
- [x] A typed password is not echoed in the success message (`does not echo a typed password in the success message`).
