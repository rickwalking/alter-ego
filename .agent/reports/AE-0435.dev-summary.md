# AE-0435 — Dev summary

Branch `feat/ae-0435-blog-en-gate-timeout` from `origin/main` (4f811e6fd2). T1 bugfix,
backend only. Root cause with file:line and the prod evidence are in the ticket and the PR body.

## What changed

- **Stage budgets (F-01).** The single 900 s run bound is gone. Text stage (writer + both
  gates + EN repair): `BLOG_GENERATION_TEXT_TIMEOUT_SECONDS` (1800). Images:
  `BLOG_IMAGE_WAVE_TIMEOUT_SECONDS` (360) x ceil(slots / concurrency); on timeout the
  finished images are attached, unfinished slots get `image_timeout`, the run ends
  `partial` + recoverable (retry = images-only). Values from 12 prod runs (ticket table).
- **EN language gate (F-02).** `blog_english_gate.py`: the carousel's
  `wrong_language_detail` on every EN section, no model. Portuguese → retranslate the gated
  PT with the editor translation (max 2, failed calls count); still Portuguese → no
  `translations.en`, `partial` + `en_translation_wrong_language`.
- **Cause.** Writer prompts v2 (judge/rewrite/draft told the language to keep); the gate
  discards an EN rewrite that switched to Portuguese. Prod: the only 2 posts with an EN
  rewrite pass are the 2 Portuguese ones.
- **Editor translation** refuses a Portuguese answer (`blog_translation_wrong_language`).
- **Repair command** `python -m rag_backend.scripts.regenerate_blog_en` (scan, read-only)
  / `--apply --only <id>` (versioned EN replace).
