## What changed

- **Auth probe after every stream error.** `workflow-stream-probe.ts` sends GET workflow/state
  through `apiCall`, so a 401 runs the existing session-expired redirect (AE-0429/AE-0431),
  and the stream is never reopened. 403 also stops. 404 disconnects. 200 applies the
  refetched state. Network errors and 5xx back off.
- **Real backoff with a cap.** `use-workflow-stream-reconnect.ts` walks the whole
  `EDITORIAL_WORKFLOW_POLL_BACKOFF_MS` array (the last delay is reused), up to
  `EDITORIAL_WORKFLOW_SSE_MAX_RECONNECT_ATTEMPTS` (5). After that the transport mode is
  `disconnected`, and every create step shows the "Live updates disconnected" alert with Retry.
  The budget resets when a stream opens, and a reopened stream refetches the state.
- **Tab visibility regain.** A live stream refetches the state. A dead stream is probed and
  reconnected.
- **Stale phase progress (UI side).** `CreateWorkflowProgress` shows `phase_progress` only when
  its phase tag maps to the current phase (`generating_images` maps to `images`).
