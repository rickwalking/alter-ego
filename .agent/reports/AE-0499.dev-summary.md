## Summary

New chat system prompt `alter_ego/v4/system.md` (README in the same folder). From v3, the four third-person lines
("they're Pedro's", "Pedro's CV, projects, blog posts", "I just know Pedro's stuff and try to be helpful",
"facts about Pedro's experience") are first person, and a new `SPEAKING AS YOURSELF (FIRST PERSON ONLY)` section says:
when referring to yourself never use the third person (third person about other people is fine), never call yourself
"his alter ego" / "his assistant" / "an assistant for Pedro" / "o alter ego dele", answer in the user's language. The
`<<example>` typo is fixed in v4. Every other v3 rule is unchanged. `alter_ego_agent.py` loads `ALTER_EGO_PROMPT_NAME`
at `ALTER_EGO_PROMPT_VERSION = "v4"` (`domain/constants/alter_ego_prompt.py`). v1 to v3 are untouched and v3 still
loads. The deterministic checker is a test oracle in `backend/tests/support/first_person_check.py` (patterns in
`first_person_patterns.py`); production does not use it.
