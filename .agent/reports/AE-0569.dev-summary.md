# Developer Completion Report — AE-0569

readable cards
Status: Dev Complete (pending PR CI)

## Summary

Split PR B of the AE-0557 board rework (critique P1-1, P1-2, P1-4). The owner
can now find and narrow carousels on `/dashboard/workflow`: a toolbar with a
search box (`/` shortcut, case- and accent-insensitive over title + topic),
status filter chips with live counts, and a stable sort — all state in the URL
(`?q=&status=&sort=`, defaults out of the URL, `router.replace` so Back is not
spammed, Suspense boundary following the calendar page pattern). The backend
orders board rows `updated_at DESC, id ASC` so card order stops reshuffling on
the 15s poll, and the adapter finally keeps `updated_at`. Card badges now use
the semantic variant/pulse from `resolveWorkflowStatusVisual` (magenta "needs
review", pulsing cyan "in progress", teal ready, red rejected/failed), the
Published column shows the relative updated time instead of a redundant "Ready
to publish" badge, blank Rejected cards get the "Sem título" fallback,
`**`/`<strong>` markup is stripped from titles, and a description equal to the
title is blanked. Column headers show the "need you" count.
