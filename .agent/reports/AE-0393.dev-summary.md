### Summary
New bounded context `backend/src/rag_backend/modules/image_bridge/` (autopilot layout:
domain / application / infrastructure / api / bootstrap / public). It generates carousel slide
images through the Grok Bot webhook with an async OpenAI-compatible callback, and falls back to
`OpenAIImageService` on any failure (ADR-0022, `docs/architecture/grokbot-image-bridge.md`).

- **Wiring:** `container.carousel_openai_image_service` = `build_carousel_openai_service(settings,
  openai_image_service)` feeds the registry's OpenAI slot. Flag off → the same
  `OpenAIImageService` instance (AC1, tested through the container). Flag on and configured →
  `FallbackImageService(GrokBotImageService, OpenAIImageService)`.
- **Owner decision (2026-10-15, applied mid-ticket):** `deploy.yml` sets `IMAGE_BRIDGE_ENABLED=true`,
  `IMAGE_BRIDGE_FALLBACK_ENABLED=true`, `IMAGE_BRIDGE_PUBLIC_BASE_URL=https://marinssolutions.com`.
  `Settings` defaults stay false/true. **AC8 replaced:** enabled without the webhook URL or the public
  base URL → one `image_bridge_misconfigured` ERROR at startup (names only, never values) and plain
  OpenAI; startup never fails. Design doc (flags table, rollout: secrets + routine live BEFORE merge,
  smoke = post-deploy check, rollback = flag false in deploy.yml), ADR-0022 and ticket ACs (AC8, new AC12) updated.
- **Callback** `POST /api/v1/image-bridge/jobs/{job_id}/result` (no JWT; per-job token in
  `X-Image-Bridge-Token`): 202 image/error recorded · 401 same body for bad/missing token, unknown
  job, non-UUID id · 409 non-pending or overdue (overdue is expired then) · 413 Content-Length or
  streamed body > 16 MB · 422 malformed JSON/shape or invalid image (job failed). b64_json only;
  no URL is ever fetched. Pillow checks PNG/JPEG/WEBP and 512–4096 px from the header before
  decoding pixels (no decompression bombs); decoded image ≤ 12 MB.
- **Waiter:** semaphore = `IMAGE_BRIDGE_MAX_CONCURRENCY`; lazy sweep (expire overdue pending,
  delete > 7 days) before each job; `secrets.token_urlsafe(32)` token stored only as SHA-256,
  compared with `hmac.compare_digest`; webhook via httpx (15 s; non-2xx/transport error fails the
  job at once, error message carries only the status or exception type, never the URL); poll
  Postgres every 2 s by PK with the bytes column deferred; transitions are single conditional
  UPDATEs (`WHERE status='pending'`, success also `expires_at > now`); bytes read once with
  `FOR UPDATE` and nulled; `ImageOps.fit` LANCZOS → PNG at exactly 1536x1024. Failures raise
  `ImageBridgeJobError(RuntimeError)`. Logs: `image_provider = grokbot | openai_fallback`,
  `bridge_job_id`, `wait_seconds`, reason (bounded); no token, secret or base64.
- **Schema:** `image_bridge_jobs` + index `(status, expires_at)`, migration `d3e4f5a6b7c8`
  (single head on `c2d3e4f5a6b7`); registered on `Base.metadata` via the facade for prod's create_all.
- **Config surfaces:** 8 settings in `settings.py`, `backend/.env.example`, `deploy.yml` (2 secrets,
  3 owner literals, 3 `vars.*` with defaults), `docker-compose.prod.yml` (backend env — needed or the
  container never sees them). nginx `location /api/v1/image-bridge/` with `client_max_body_size 16m`
  in both configs, mirroring `/api/`.
- **Gate:** `scripts/ci/check_image_bridge_env_parity.py`, chained into `backend:autopilot-env`
  (4 surfaces; secret/plain split; compose/.env.example default false; deploy literals). Rule-fires
  tests: `backend/tests/unit/scripts_ci/test_check_image_bridge_env_parity.py` (22).
- **Smoke CLI:** `scripts/image_bridge_smoke.py` — one job end to end; prints
  `provider=… seconds=… size=WxH output=…`; bridge only unless `--with-fallback`; exit 0/1/2.
  On prod: `docker compose -f docker-compose.prod.yml exec -T backend python - < scripts/image_bridge_smoke.py`.
