# AE-0417 — Dev summary

Branch `fix/ae-0417-ci-hang-and-dates` from main `780c50fb`. PR #134.

## What changed

1. **CI hang (root cause).** `_execute_owned_run` stopped the interval heartbeat with a bare
   `cancel()`. A heartbeat caught inside a write outlived the run, wrote after its
   connections were gone, and hung loop teardown (`asyncio.runners._cancel_all_tasks`).
   Reproduced on the Pi (2 hangs in 4 runs; py-spy stack = CI's). `stop_heartbeat` (new
   `editorial_workflow_run_heartbeat.py`) cancels and waits; the run awaits it on every
   exit. After the fix: 10/10 runs of the file + `test_run_heartbeat_lock_pg.py`, no hang.
2. **CI guard rails.** `timeout-minutes`: backend Test & Coverage 30, ci-gate backend-gate
   90, deploy `test` 40. `faulthandler_timeout = 600` in `backend/pytest.ini`.
   No pytest-timeout (not a repo dependency).
3. **Locale dates.** `src/lib/locale-format.ts` (AE-0412 formats); blog cards, notification
   center, chat, calendar, knowledge card and admin users use `useLocale()`.
