### Summary
The publish step's "Gerar capa com Grok" prompt now shows the same prompt suggestions as the create wizard
(AE-0509): the curated catalogue for the carousel's topic and palette, then AI ideas on "Mais ideias".
Tapping one fills the prompt, which stays editable.

How it is wired:
- The suggestion logic moved out of AE-0509's `CoverPromptField` into `CoverPromptSuggestions` (exported
  from `@/modules/editorial`), so both prompts use one component.
- The publishing module stays independent of editorial. `CoverPickerSection` / `CoverGeneratePanel` take
  an optional `renderPromptSuggestions(fill)` and put it in the prompt field's `children` slot.
- `PublishCoverPicker` on the publish page composes it with the carousel's `topic` and palette
  (`findThemePalette` over the palette catalog, as the wizard does).
