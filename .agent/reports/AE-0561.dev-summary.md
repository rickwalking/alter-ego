### Summary

Shared web and generation-worker observability startup now schedules one bounded Langfuse credential check without awaiting it. The check uses the SDK's public projects API directly, moves blocking I/O off the event loop, applies a five-second request and await deadline, disables retries, preserves best-effort tracing on failure, and emits one safe structured outcome.

The implementation avoids the SDK `auth_check()` wrapper because that wrapper can emit auxiliary raw-exception logs. Diagnostic hosts contain only their HTTP(S) origin; userinfo, paths, queries, fragments, unsupported schemes, and malformed ports are never emitted.
