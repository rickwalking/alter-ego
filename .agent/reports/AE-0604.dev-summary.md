### Root cause
`WorkflowTimeoutRepository.reject` (`backend/src/rag_backend/infrastructure/database/workflow_timeout_repository.py:119`)
flipped `phase_status` to `rejected` without touching `lock_version`. The owner review CAS
(`api/routes/carousels/editorial_workflow_routes_validate.py:299` → `CarouselProjectWriteOwner.bump_resume_lock_version`
→ `OptimisticLockService.bump_carousel_version`, `application/services/optimistic_lock_service.py:93`) compares
`lock_version` only, so an approve at the version read before the reject still won and drove a rejected carousel.
