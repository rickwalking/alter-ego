preflight. If either is empty or blank it raises `AdsCallError("meta_page_missing", permanent=True)` with no HTTP
request. The worker tick already stores any launch error as `failed` with `error_code`, so the request ends
`failed / meta_page_missing`, readable by the bot on the boost-request routes. Caps, approval flow and schema are
unchanged (Pedro's decision, 2026-10-31).
