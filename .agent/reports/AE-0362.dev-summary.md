### Summary
Hotfix for the 2026-10-14 prod escalation (carousel 8e350d6e, `outline_slide_count_mismatch`).
The autopilot created 6-slide projects while the editorial pipeline always builds the
presentation contract's 7 slides. Autopilot projects now use `CAROUSEL_DEFAULT_SLIDES_CONFIG`
(7), and the gates' expected count is the project's presentation contract `slide_count`
(the same source the outline agent uses), with `slides_config` only as a fallback. The images
gate also required 1080x1350 on the raw hero images (OpenAI renders 1536x1024), which could
never pass; it now requires one present JPEG with a decodable size per expected slide.
