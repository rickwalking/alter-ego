### Summary
Every saved change of a carousel's Instagram caption or LinkedIn post (PT/EN) is now a version in
`content_versions` (Pedro, Q9: reuse the table, fix its unique index through a deploy one-shot), and the
owner sees the history under each editor and can restore a version.

- **Recording:** `CarouselCopyEditService.save` stages one `carousel_copy` version per text the save
  changes (snapshot `{field, text}`, the author, the time) before `update_project` commits, so the
  versions land in the save's transaction. The first change of a text also keeps the text it replaced
  (no author: the generated text). An unchanged text records nothing. Numbering is per carousel.
- **Routes:** `GET /api/carousels/{id}/copy/versions` (owner or admin; newest first, with the author's
  name) and `POST /api/carousels/{id}/copy/versions/{n}/restore` (owner or admin, `If-Match`), which saves
  the version's text through the same guarded save (stale lock 409 `version_conflict`, run in progress
  409, published caption 409 `caption_published`, unknown version 404) and records the restore as a new
  version (`restored_from`).
- **Schema:** the unique index moves from the global `(content_type, version_number)` to
  `(content_id, content_type, version_number)`: model, Alembic revision `c7d8e9f0a1b3`, and the
  idempotent one-shot `python -m rag_backend.scripts.content_versions_index --apply --verify`, run by
  `deploy.yml` after the palette timestamptz step (same never-block-the-stack shape: exit captured, job
  failed only after the stack is up). Prod checked read-only on 2026-10-22: the table is empty and has the
  global index.
- **UI:** "Histórico" under the caption and LinkedIn editors on the publish page and in Revisão final:
  number, language (LinkedIn), author or "Texto gerado", time, text; "Restaurar" on older versions,
  disabled while that text has unsaved edits; a refused restore says why.
- **Layering:** the store is built in the composition root (`bootstrap/carousel_copy_versions.py`), so
  the copy routes add no `api -> infrastructure` import (architecture ratchet unchanged).
