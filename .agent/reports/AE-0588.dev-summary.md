## Summary

Pedro's decision (2026-11-01): fix the root cause, content generation must fit the
slide length budgets by itself. Two parts, both reading the limits from the same
contract values the validator enforces (`copy_budget_limits.py` resolves every
limit through `heading_budget_for_slide_type`, `body_budget_for_slide_type` and the
item keys of `field_budget`, plus `HOOK_MAX_WORDS` / `MIN_CONTENT_BODY_WORDS` when the
policy declares those rules):

- (a) Prompt budgets. The drafting instruction's per-slide block now lists "Copy
  limits of this slide" (template `carousel_copy_budget/v1/slide_limits.yaml`), so
  every content family (v6, Radar v7, POV, POV news) sees this slide's limits. New
  `carousel_pov/v3/content.yaml` and `carousel_pov_news/v3/content.yaml` drop the
  hardcoded per-role numbers (v1's sub-hook "até 80" contradicted `pov_hook_v1`'s
  40); `POV_PROMPT_CONTENT_VERSION = "v3"`. The translation request carries
  `limits` per slide and the new `carousel/v10/slide_translations.yaml` requires every
  English field to fit (`CAROUSEL_TRANSLATION_PROMPT_VERSION` -> v10).
- (b) Shorten step before the presentation validation. In the content ensure,
  after drafts / translations / sanitize and right before the fail-closed review
  build, `run_budget_step` builds the localized slides like the review does, asks
  the fast model (one call per attempt, max 2) to rewrite only the fields with
  `heading_too_long` / `body_too_long` / `copy_too_many_lines` (PT and EN, heading,
  body, `features|summary_points|actions[i].title|body`), and accepts an answer only
  when it is new, shorter (or fewer lines), EN not Portuguese, adds no persona
  forbidden phrase, and re-validating the deck adds no new violation (so broken
  `**`, lost final punctuation, under-minimum words, hook over 10 words, repeated
  sentences are rejected). Best effort = shortest accepted rewrite; a rejected answer
  leaves the field; a model error keeps the copy. Changed slides go back into the
  drafts and EN translations through `apply_localized_slide_edits` (owner-edit
  path); the persona voice score is recomputed for changed slides (fingerprints keep
  the others). Validators, thresholds, severities, contracts and gates unchanged.
