## Root causes

1. `slide_scaffold_recovery.py` matched only `## PT` / `**PT**` / `**EN**`
   markers; `**PT-BR**`, `PT: Heading:`, `**CTA creator:**` fell through
   into visible copy (F-03/F-04).
2. `contains_drafting_scaffold` matched only `SLIDE N|TITLE|BODY|KEY
   POINTS:` — no locale markers, no field labels (gate never blocked).
3. `render_presentation_policy_context` rendered raw schema field names
   (`cta_creator_name: max 60 characters`) into the drafter prompt; the
   model echoed "CTA creator: radar IA." (F-04).
4. No per-locale emphasis rule; the v8 translator kept PT `**` in EN (F-09).
