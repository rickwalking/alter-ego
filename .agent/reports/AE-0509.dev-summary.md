### Summary
Prompt suggestions for a new cover photo (Pedro's decision: curated catalogue first, "Mais ideias" from the
fast LLM queue on demand). The Slide 1 photo section of the create form (POV modes) gets an editable prompt
field (`CoverPromptField`, exported from `@/modules/editorial` so the Grok cover dialog can reuse it) with six
curated suggestions (frontal, three-quarter, low angle, desk, gesture, close-up) filled with the selected
palette's name and colours (neutral wording for "auto") and a nod to the topic (cut at 80 characters).
Tapping one fills the field, which stays editable; the prompt is local and not saved (the hint says so).
"Mais ideias" (topic of 3+ characters) posts only `{topic, palette|null, locale}` to
`POST /api/carousels/cover-prompt-ideas` and replaces the list with 3-6 AI ideas; a failure shows a retryable
error and keeps the curated list.

Backend: request schema rejects unknown fields (422), strict hex colours, palette name without markup, topic
3-500. Prompt `agents/prompts/cover_prompt/v1/ideas.yaml` (topic and palette line sanitised, topic delimited
as data, the model told never to invent personal details). Every idea is re-checked (whitespace collapsed,
12-400 characters, no `< > { }`, no case-insensitive repeats, at most six). Fewer than three usable ideas →
one more call; still fewer, or the LLM failing/timing out (12 s per call) both times → 503
`cover_prompt_ideas_unavailable`. Editor or admin only, 10/minute per user, nothing stored. Token cap 1500 and
temperature 0.9 bound on the fast chat model. Langfuse trace: phase/agent `cover_prompt_ideas`, user id,
content type `carousel`.
