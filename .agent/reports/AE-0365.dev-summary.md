`slides_total` (7) hero images, but the image phase only illustrates
`filter_image_slides(slides)` (slide types in `IMAGE_SLIDE_TYPES` with an image prompt). The
CTA slide uses the owner avatar, so a real run stores 6 and every run revised and escalated.

more than `MAX_SLIDES` fails closed. The per-file present / JPEG / decodable-size check is
unchanged (a zero-byte file revises). No migration.
