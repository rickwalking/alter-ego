| Item | Status | What changed | Tests |

| **Q1** notifier stall | fixed | `SqlAutopilotEventSource.recent` now runs two queries, each with its own `OUTBOX_SCAN_LIMIT`: the re-scan window (`cursor - 10 min < created_at`, position <= cursor), then the rows after the cursor by `(created_at, event_id)`. A window full of settled rows can no longer use up the limit. | `test_new_event_is_read_past_a_window_full_of_settled_events` (150 settled + 1 new; failed before the fix), the existing r2 cursor tests |
| **Q2** silent 24 h hold | fixed | New `application/publish_hold.py` (`HeldRunCheck`). When `claim_run` is refused and the run has a fresh stored container with no post id, the job reads `container_status` once. `PUBLISHED` / `FINISHED`: `take_over_held` (CAS on a stale or empty claim only), then the normal resume path (`finish_container`, which recovers with the R3 matching or calls `media_publish` once). `ERROR` / `EXPIRED`: take over and fail with `instagram_container_failed`. `IN_PROGRESS` or an unreadable status: wait. If a hold lasts over 30 min, the owner gets one `publish_held` Telegram notice. `state_reason=publish_held_by_container` records that it was sent; the attempt count is unchanged. New port methods: `InstagramGraphGateway.container_status` and `PublishClaims.take_over_held`. | `test_a_published_or_finished_container_is_finished_under_the_claim[PUBLISHED/FINISHED]`, `test_an_error_or_expired_container_fails_the_run[ERROR/EXPIRED]`, `test_an_in_progress_container_keeps_waiting_silently`, `test_a_status_read_failure_keeps_waiting`, `test_a_live_holder_keeps_the_run_even_when_the_container_is_finished`, `test_a_run_without_a_stored_container_is_not_probed`, `test_a_hold_longer_than_30_minutes_is_reported_once`, `test_a_hold_under_30_minutes_is_not_reported`, `test_the_held_notice_renders_as_its_own_telegram_kind`, `test_held_takeover_only_replaces_a_stale_or_empty_claim[*]` (Postgres), `test_stepped_gateway_reads_a_held_container_status`, `test_atomic_gateway_has_no_container_status` |
| **Q3** escalation close ignores a fix | fixed | `sweep` now runs the wake check before `_close_abandoned`. Before closing, the close reads the gate. A carousel back at final review / awaiting human at a new lock version is never closed. A gate read failure also keeps the run open. When there is no notifier, such a run is first recorded once with `notifier_unconfigured` (new `RunRecoveryStore.mark_unnotified`, which also restarts `updated_at`). It may close only after that record, 72 h later. A configured notifier wakes it instead. | `test_an_old_fixed_escalation_is_woken_not_closed`, `test_a_fixed_escalation_past_the_wake_scan_is_not_closed`, `test_an_unreadable_carousel_is_not_closed`, `test_a_fixed_escalation_without_a_notifier_is_recorded_then_closed`, `test_a_recorded_unnotified_run_wakes_when_the_notifier_returns`, `test_an_unfixed_notifier_unconfigured_escalation_still_closes`, `test_unnotified_mark_records_the_reason_on_escalated_runs_only[*]` (Postgres). The first five failed on the old code. |
| **Q4** manual ledger race | fixed | After `claim_manual` succeeds, `_without_run` reads the ledger again. If a post id appeared in the meantime, it is returned and the claim is released. Otherwise the fresh row's container is resumed. | `test_the_container_stored_before_the_claim_is_resumed`, `test_a_post_id_stored_before_the_claim_short_circuits` (both failed before the fix) |
| **Q5** research fetch regressions | fixed | `GuardedDocumentFetcher.fetch` wraps every hop in `asyncio.timeout(RESEARCH_FETCH_DEADLINE_SECONDS=15)`. Only `text/html`, `application/xhtml+xml` and `text/plain` are read. Anything else, a missing `Content-Type` included, raises `UnsupportedResearchContentError`. All three callers (`research_enrichment._scrape_one`, the `scrape_url` @tool, `writing_style_profile`) already catch `Exception` and skip the source, which is what the old Chromium failure did. `text/plain` is returned without Chromium. The client sends `RESEARCH_REQUEST_HEADERS` (Chrome UA, Accept, Accept-Language) from `domain/constants/url_safety.py`. The charset comes from the header, else `<meta charset>` / `http-equiv`, else UTF-8 with `errors="replace"`; an unknown label falls through. The module docstring says JavaScript-built pages come back as their static HTML. | `test_slow_hops_together_hit_the_overall_deadline`, `test_the_deadline_is_15_seconds`, `test_non_text_documents_are_skipped[pdf/png/octet-stream/none]`, `test_text_documents_are_fetched[html/xhtml/plain]`, `test_a_skipped_document_keeps_the_original_research_content`, `test_plain_text_is_returned_without_chromium`, `test_the_production_client_sends_browser_headers`, `test_the_page_charset_is_honoured[*]` (6 cases) |
| **Q6** DNS-prefetch / preconnect leak | fixed | Chromium launches with `--dns-prefetch-disable`. `strip_resource_hints` removes `<link rel=dns-prefetch\|preconnect\|prefetch\|preload\|modulepreload\|prerender>` before `set_content`. It is case-insensitive, handles quoted or unquoted values, and keeps other links. | `test_resource_hints_are_stripped_and_other_links_kept`, `test_chromium_runs_without_dns_prefetch_on_stripped_html` |
