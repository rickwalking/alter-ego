### Review fixes (2026-10-23)
- Blocker: `delete_by_document` used `index.delete(delete_all=True, namespace=ns)` on the shared
  `personal` / `public` namespaces, so deleting, reprocessing or rescoping one document wiped every
  other document of that scope. It now deletes with `filter={"document_id": {"$eq": id}}`. Tests run the
  real `PineconeVectorStore` and pipeline over `tests/pinecone_index_fakes.FakePineconeIndex`, an
  in-memory index that holds vectors per namespace (unit: store, rescope, reprocess, delete; integration:
  rescope and delete through the API). With the old code 4 of the 5 unit tests fail.
- `KnowledgeService.change_scope` deletes the chunks from the new namespace again when anything fails
  after the re-index, the commit included (`pipeline.drop_chunks`).
- `change_scope` and `reprocess` lock the document row first (`get_by_id_for_update`,
  `SELECT ... FOR UPDATE`).
- The PATCH answers 409 for a document in a system scope (carousel, internal); the card shows a
  "Sistema" badge and no switch, and such a document is listed only under "Todos".
- `useDocumentScopeChange` tracks in-flight and failed ids per document (shared `hooks/id-sets.ts` with
  the retry hook).
- No ticket id in test emails or test docstrings.
