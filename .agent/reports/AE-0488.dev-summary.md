### Summary
/chat QA CHAT-01, CHAT-03 (backend half), CHAT-04.
- The Alter-Ego search tool stops after 3 searches per turn (`SearchToolOptions.max_calls`).
- The agent loop is capped at 25 steps. If it runs out, the visitor gets an honest "not in my knowledge yet" reply in
  their language (pt/en), and the server logs `alter_ego_step_limit_reached`.
- Any stream failure is logged as `chat_stream_failed`, with the conversation id, the error type and the traceback.
- The client gets a generic error event: no exception text, no docs URL.
- An apology assistant turn closes the failed question (the partial reply is rolled back), so the next turn does not
  answer the old question.

### Acceptance Criteria Implemented
- [x] Step limit → honest reply in the visitor's language, logged.
- [x] Search budget of 3 per turn. The carousel chat has no budget.
- [x] Failures are logged server-side, and the client message is generic.
- [x] Apology turn after a failure; the partial reply is never saved.
