## What changed

- The workflow tick, after the Instagram publish step and the autopilot runner, delivers pending `content.autopilot.*` notices. The tick still runs when `autopilot_enabled` is false, so a run that is already `awaiting_owner` can be notified.
- A ready run sends one album of up to 10 PT JPEGs (multipart from disk, never a public URL) and one keyboard message: Approve, Rework, Reject. One slide uses `sendPhoto`. No slides still send the keyboard. Message ids are stored in `telegram_message_ids`.
- The same revision is sent once. Status events (escalated, failed, published, publish failed with Retry, Instagram token expiring) and the 24 hour reminder are deduped the same way.
- HTTP 429 waits for `retry_after` in process when it is at most 60 seconds, up to three times, and does not count as a failed attempt. A longer `retry_after` is left for the next tick. Other errors retry on later ticks, then stop after three.
- An empty bot token or owner chat id makes the notifier a no-op log line. The runner escalates `generating` / `reworking` with reason `notifier_unconfigured` instead of emitting `ready_for_owner`.

## Deviations

- Notices are read from the outbox on the worker tick. The relay only publishes to Redis, and nothing consumes `content.autopilot.*`.
- The revision key is the editorial `lock_version` captured when the run becomes ready.
- `telegram_message_ids` stays a JSON list until the first notice, then becomes a ledger object. Saving the ledger does not move `updated_at`.
- Unconfigured means the bot token or the owner chat id is empty. Escalation happens before `awaiting_owner`, because that state cannot move to `escalated`.
- One JPEG uses `sendPhoto`. A reminder repeats the Approve / Rework / Reject keyboard.
- Telegram copy constants live in `notify_constants.py` so `constants.py` stays under 400 lines.
- Untrusted JSON is typed as `object`, matching the rest of the autopilot module.

## Known risks

- The newest 100 outbox rows are scanned each tick. An older undelivered notice can sit behind a flood.
- There is no producer yet for `content.autopilot.ig_token_expiring` (AE-0358). The dispatcher renders it when the row exists.
- Button presses are AE-0356. Production secret wiring is AE-0359.
