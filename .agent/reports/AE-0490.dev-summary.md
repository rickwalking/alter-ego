## Developer Completion Report
Ticket: AE-0490
Status: Review

### Summary
Admin "Redefinir senha" and self-service change-password returned 500 "Database Error". Both only change
`hashed_password`, so `PostgresUserRepository.update` re-assigned an unchanged `updated_at`; the column's
`onupdate=func.now()` then set it in the database and the flush expired it, and `model.to_entity()` lazy-loaded it
inside the async session → `MissingGreenlet` → 500. Reproduced in the app flow (SQLite integration tests that had
pinned the 500) and at the repository level on Postgres 16. Fix: `await session.refresh(model)` after the flush.
