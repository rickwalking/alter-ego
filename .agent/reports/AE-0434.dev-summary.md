## What changed

- **Renderer follows the images phase.** `role_layouts.deck_artwork_slides` (the images node's
  `artwork_slide_numbers`, sized to the deck) feeds `_RenderOptions.artwork`. Every
  lower-third strategy forwards it to `LowerThirdConfig.show_artwork`. Slides outside the
  set render `.slide-artwork.slide-artwork-none` (gradient, no `<img>`). Fixed contracts are
  unchanged, and an explicit cover still wins.
- **Preflight names the cause.** `playwright_artwork_check.ensure_artwork_files` runs in
  `export_slides` before Playwright. If a local artwork file is missing, it raises
  `export_preflight_failed: slide_artwork_missing: slide_N`.
