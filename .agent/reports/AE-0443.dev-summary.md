## What changed

- **Stats:** the landing renders `data.total` from `fetchCompletedProjects(5)`.
  That helper previously queried `?public=true` only, so `total` counted every
  public project (26 on prod). It now also sends `status=completed`; prod
  returns 15 and the stat shows 15. Kept "8+ Years Engineering", dropped the
  "∞ Topics" stat, added "Published Carousels" / "Carrosséis publicados".
- **Cards:** whole-card links — Chat → `/chat`, Blog → `/blog`, Visual Carousels
  → `/carousels` — with accessible names and a `focus-visible` ring.
- **Header:** removed Login; added Carousels after Blog. `/login` remains
  reachable by URL; auth and the dashboard header untouched. `/carousels` is
  registered as a public route; the page itself is AE-0444.
- **Hero:** removed the "Alter-Ego v2.0" badge and `hero.badgeVersion` from both
  locales.
- **Copy:** fixed PT "Especializo me", removed the "knows everything/sabe tudo"
  overclaim, corrected the latest-posts subtitle to describe carousels, and
  standardized "Alter-Ego"; pt/en keys stay in sync.
